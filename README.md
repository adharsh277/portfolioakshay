# Akshay Unnikrishnan | Premium Automotive Systems Portfolio

A high-end, minimal Swiss-editorial styled personal portfolio website built for **Akshay Unnikrishnan**, M.Sc. Commercial Vehicle Technology student at RPTU Kaiserslautern, Germany.

## Core Identity & Scope
This portfolio is tailored to showcase expertise in **Automotive Systems Engineering, Simulation, and Validation**, highlighting academic project executions and capabilities without software-centric or DevOps deviations.

## Key Technical Features
1. **Interactive Canvas Visuals**:
   - **Hero Systems Diagram**: Visual schematic tracing sensor loops (Sensors → Perception → Controller → Actuation → Vehicle Model → V&V Core) reacting to mouse parallax.
   - **Project Cases**: Specialized canvas widgets drawing trajectory prediction models, hybrid-electric energy flows, 1-DOF damped step-stabilizations, and rotating CAD assembly wireframes.
   - **Capabilities Node Map**: Dynamic network mapping systems engineering competencies (Systems, Vehicle Tech, Communication, Simulation, ML, Quality) with node hover triggers.
   - **Academic Drawings**: Mechanical tensile stress-strain plots and block diagrams.
2. **Bilingual Translation Support**:
   - Dynamic English (EN) and German (DE) localization toggles utilizing custom data-attribute dictionary swapping in vanilla JS.
3. **Verified Credentials Drawer**:
   - Minimalist document-style cards and popup modal panel confirming course/certifications status.
4. **Technical entry animations**:
   - Editorial scroll-reveal baseline draws and dynamic left-border card height expansions.

## Technologies Used
- HTML5 (Semantic Structure & ARIA Accessibility rules)
- Vanilla CSS3 (Custom Grid coordinates & transitions)
- Vanilla ES6 JavaScript (HTML5 Canvas Engine, IntersectionObserver API, Dynamic state localization mapping)
